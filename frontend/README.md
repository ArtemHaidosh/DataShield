# Frontend - DataShield

Vue 3 + Vite interface for document anonymization.

## Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Dev Server
```bash
npm run dev
```

Opens on http://localhost:5173

### 3. Build for Production
```bash
npm run build
```

## Features

- ✅ Drag & drop upload
- ✅ PDF, DOCX, TXT support
- ✅ Real-time results
- ✅ Statistics display
- ✅ Responsive design
- ✅ Tailwind CSS

## API

Connects to `http://localhost:8000/api/anonymize`
